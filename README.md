# Data Science Internship — Week 1 Assignment

**Organization:** WeIntern Pvt Ltd

## Objective
Develop data cleaning, analytical thinking, visualization, and reporting skills using an e-commerce dataset.

## Dataset
- **File:** `Ecommerce_data.csv`
- **Description:** E-commerce data containing customer, product, order, sales, delivery, and profit information.
- **Size:** 113,270 rows and 21 columns, as observed during initial inspection.

## Tools and Technologies
- Python
- Google Colab
- pandas
- Matplotlib
- Seaborn
- GitHub

## Assignment Tasks

### Task 1: E-Commerce Dataset Cleaning
- Inspect the dataset structure and data types.
- Check missing values and duplicate records.
- Validate numerical fields and dates.
- Document cleaning decisions.
- Save a separate cleaned dataset.

### Task 2: Sales Data Analysis
- Calculate key performance indicators (KPIs).
- Analyse sales by product, category, and time.
- Investigate customer purchasing patterns.
- Document 5–8 evidence-based observations.

### Task 3: Visualization Challenge
- Create a bar chart, line chart, and pie chart.
- Build a dashboard mockup.
- Explain the insights communicated by each visualization.
